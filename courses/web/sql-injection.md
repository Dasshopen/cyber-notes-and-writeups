# Injection SQL — Notes de séance

## Contexte

Le cours utilisait un moteur de recherche comme support d'étude. Le journal
décrivait une progression depuis une réponse anormale jusqu'à l'étude du schéma
de la base de données.

## Démarche observée

1. Conserver une requête normale comme référence.
2. Observer l'effet d'une modification du paramètre.
3. Étudier la structure des résultats retournés.
4. Distinguer les colonnes utilisées par la requête de celles affichées à l'écran.
5. Interpréter les métadonnées de la base dans le contexte du moteur utilisé.

## Limites du brouillon

Les exemples initiaux ne précisaient pas le moteur, le schéma complet ou les
réponses du serveur. Une des requêtes était syntaxiquement incomplète. Ils ne
sont pas transformés ici en une procédure générique de récupération de données.

Les exemples de challenge déjà documentés se trouvent dans les write-ups et les
fiches pratiques, avec leur contexte. Cette note de séance reste une synthèse
méthodologique, pas un script testé.
